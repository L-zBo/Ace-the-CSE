# 跨卷同题答案矛盾修复（2026-08-11）

## 这轮解决的问题

同一道真题在多套卷里出现，答案本该一样。全库审计里 `dup_cross_paper` 一直
被当成脏数据挂着，这轮把它做成关联功能之后，顺手拿它反查答案 ——
**对不上就说明至少有一份是错的**。

```
检查 1706 组跨卷同题
  答案矛盾 229 组 / 720 道题
     多数派明确 75 组（少数派可疑题 87 道）
     平票无法判定 154 组
```

对 87 道少数派可疑题逐题回本卷 PDF 复核，**改了 18 道**，矛盾组
229 → 213、涉及题 720 → 644。

## 一个必须写下来的认知更正

`material/` 里那些「答案及解析」PDF **是培训机构整理版，不是官方发布的标准答案**。
不同机构会给出相反答案，实测：

> 2020 年联考「情商班」接语选择题
> - 宁夏那份 PDF：「正确答案 C，全站正确率 26%，易错项 B」
> - 安徽那份 PDF：「正确答案 B，全站正确率 60%，易错项 C」

两家机构互相打脸，而**库内答案本来就是从这些 PDF 提取的**。所以
「PDF 与库内一致」是同义反复，不构成独立证据。

第一版脚本按「官方支持库内现值」把 16 道判成「多数派错了」，那个结论是错的 ——
它们只是在复读数据来源。真正有价值的信号只有一个：

> **库内值 ≠ 本卷 PDF 值，且本卷 PDF 值 == 其他省同题的多数派**

这说明当初从这份 PDF 提取时抄错了，且有跨省同题佐证。只有这一类才改。

## 证据链

每道改动都同时满足四条：

1. **编号对齐** —— 在真题 PDF 里定位第 N 题，库内题干的连续子串命中该块，
   证明「库里的第 N 题 == 官方卷的第 N 题」
2. **逐项分析命中** —— 同卷解析 PDF 第 N 题的块里有「{答案字母} 项……」的
   逐项判定，且与题型（选非题 / 选是题）一致
3. **多份 PDF 不打架** —— 同卷有多份解析 PDF 时答案必须一致，否则弃权（弃权 3 道）
4. **跨省佐证** —— 其他省同题的多数派与 PDF 答案相同

## 副产品：暴露出 8 道串题解析

改完之后 `answer_vs_explanation` 从 91 涨到 99。查清了，**不是新引入的问题，
是把原本藏着的问题翻出来了**：这 8 道的库内答案与解析是**配套地从同一段串题
解析里抄来的**，两者一致所以审计发现不了。

实证两例：

- `provincial_fujian_2023#009`（革命遗址常识题），库内解析全文是
  「故正确答案为 D。【文段出处】中国经济网《创新不是割蕉加梅，而是与虎添翼》」
  —— 一道言语题的解析残片
- `provincial_neimenggu_2023#007`（经济政策常识题），库内解析是
  「第二空……A 项『反思』侧重思考……故正确答案为 A」—— 逻辑填空题的解析

原来是「答案和解析一起错、彼此自洽」，现在变成「答案对了、解析仍错但前端有
矛盾提示」。这 8 道的解析回填另行处理。

## 复现

```bash
python scripts/audit_cross_paper_answers.py      # 定位矛盾 -> reports/cross_paper_answer_conflicts.json
python scripts/fix_cross_paper_answers.py        # 预览复核结果
python scripts/fix_cross_paper_answers.py --apply
python scripts/generate_question_index.py        # answer 进索引，必须重建
python scripts/generate_cross_paper_links.py
```

脚本幂等（`current` 从题库实时读，不用报告快照）。完整逐题结论见
`reports/cross_paper_answer_resolution.json`。

## 剩下没动的

| 情形 | 数量 | 为什么不动 |
|---|---|---|
| 本卷 PDF == 库内 | 30 | 提取没错，是跨机构版本分歧，改了等于拿一家覆盖另一家 |
| 本卷 PDF 给出第三个值 | 5 | 三方都不同，需人工定夺 |
| 同卷多份 PDF 打架 | 3 | 弃权 |
| 真题 PDF 锚不到题干 | 20 | 编号对不齐，锚定失败就不能采信答案 |
| 解析 PDF 抽不出答案 | 25 | 格式不支持或该题无解析 |
| 题干过短 | 4 | 锚不住 |
| 平票组 | 154 组 | 多数派规则失效，只能纯靠 PDF，成本高收益低 |
