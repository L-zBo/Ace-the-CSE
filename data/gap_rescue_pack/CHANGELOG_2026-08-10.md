# 2026-08-10 批量订正：选项串题污染 + 答案字段

## 起因

审计发现两类由 PDF 抽取「跨题串行」造成的污染，都是入库时就带进来的旧账：

1. **选项正文里串进别的题的整组选项**。典型形态：

   ```
   "D": "在国外合法设立但尚未在我国民政部门登记的某环保基金会 B、建设一支听党指挥、
         能打胜仗、作风优良的人民军队 D、确保到 2020 年全面实现机..."
   ```

   前半截是本题 D 的真实内容，后面整段是另一道题的选项。用户看到的就是一坨读不通的
   文字，这道题实际上没法做。全库扫出 **875 道题 / 1065 条选项**受影响。

2. **answer 字段与官方答案不符**，另有 36 道多选题的 answer 存成 `'ABCD'` 拼接串，
   而前端三处判分逻辑一律走 `Array.isArray(answer)` 分支，字符串会被包成
   `Set{'ABCD'}`，`has('A')` 恒为 false —— 这些题**提交后正确选项一个都不高亮，
   判分永远算错**。

## 走过的弯路

第一版 `fix_option_crosstalk.py` 用「截断」：在选项正文里找外来标号，截掉后半段，
再拿截断结果回 PDF 里搜，命中就采信。

**这是假证据。** 同一套卷里任何一段文字都能在该卷 PDF 里搜到，命中只证明「这段话在
这份卷子里」，证明不了「它是这道题的这个选项」。实测截出来一堆
`A．畜牧业是其支柱产业`、`88 325` 这种垃圾，而且全部「验证通过」。已推翻重写。

## 现在的证据链

### 选项订正（`scripts/fix_option_crosstalk.py`）

1. 官方**真题** PDF（`material/`，2555 份）按行首题号切块，取第 N 题的块
2. 要求该块正文包含库里题干前 16 字 —— 题号 + 题干双锚，锁定就是这道题
3. 解析该块的 A/B/C/D 四个选项
4. **要求该题至少 2 个未受污染的选项与 PDF 完全一致**（同题互证），证明解析出来的
   这组选项确实和库里这道题对得上，而不是错位到了隔壁题
5. 再设一道护栏：新值长度不得超过同题其余选项最长值的 2 倍 + 30 字。资料分析末题的
   D 后面直接跟下一段材料，PDF 块里没有标号可截，不设上界会把整段材料吞进去

任何一步不过就不动，进报告等人工。

### 答案订正（`scripts/resolve_answer_conflicts.py` / `_gk.py`）

1. 真题 PDF 里按题干定位，确认原卷题号 == 库里题号
2. 同一套的答案解析 PDF 里取第 N 题的【答案】

两步都过才采信。

## 结果

| 项 | 数 |
|---|---|
| 订正选项 | 473 条（387 道题） |
| 订正 answer 字段 | 28 道 |
| 多选 answer 规范化为数组 | 36 道 |
| 涉及数据文件 | 231 个 |

订正明细逐条落在 `reports/applied_changes_2026-08-10.json`（含每条的 old / new）。

## 没修的，以及为什么

| 情况 | 数量 | 原因 |
|---|---|---|
| `option_no_anchor` | 455 道 | 题号或题干在 PDF 里锚不上。抽样核查发现相当一部分是 PDF 该页为图片层（无文字），或多栏排版把题号打散 |
| `option_pdf_also_dirty` | 65 道 | 锚定成功，但 PDF 解析出来的那个选项本身也是串的 |
| `option_too_long` | 64 道 | 长度护栏拦下，多为资料分析末题 |
| `answer_vs_explanation` | 96 道 | 双向校验没过，PDF 里取不到可信答案。**解析结论不能当证据改答案**，那是推导不是证据 |

`institution-xingce-changshi-2020-a-005` 是个典型：官方 A 类真题 PDF 里第 5 题只印到
C 选项，D 选项所在的整页是图片层，源头就没有文字可抽。这类只能靠 OCR 或换源，本轮不动。

## 迁移

本批订正的 231 个 JSON 已整份复制到 `files/` 下同名路径，可直接覆盖旧机器项目。

注意 `material/` 未入库（`.gitignore` 第 57 行），换机器后**无法重跑脚本复现**，
只能用 `files/` 覆盖。
